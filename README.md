# IGCSE AI Tutor

An AI-powered assistant designed to help IGCSE ICT students understand exam questions, improve answers, and learn key concepts in simple English.

## Problem

Many IGCSE ICT students struggle with:
- Understanding exam questions
- Using correct keywords from the mark scheme
- Writing clear answers in English
- Connecting theory with practical ICT tasks

## Goal

The goal of this project is to build a simple AI tutor that can:
- Explain ICT questions in simple language
- Give sample answers
- Highlight important keywords
- Help students improve their answers
- Support teachers with classroom practice

## First MVP

The first version will allow students to paste an ICT question and receive:
- Simple explanation
- Step-by-step guidance
- Model answer
- Important keywords
